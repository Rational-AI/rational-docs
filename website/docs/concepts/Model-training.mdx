# Model training

**Training** is how a model is built. It reads a huge number of examples, guesses what comes next, and after each guess adjusts itself a little to guess better. Nobody writes its rules by hand: the model picks up the patterns in its [training data](/concepts/Dataset-and-training-data).

The aim is a model that handles questions it has never seen, not one that memorizes its examples.

## The stages

| Stage | What happens | Who does it |
| :-- | :-- | :-- |
| Pre-training | The model learns general language from a very large, broad collection of text | The model maker |
| Fine-tuning | It learns a task, a format or a domain from a smaller set of examples | The model maker, or you |
| Alignment | People's ratings teach it to give helpful, safe answers ([RLHF](/concepts/RLHF)) | The model maker |

Training changes the model. Using it doesn't: see [Inference](/concepts/Inference).

## In Rational AI

You don't pre-train models in Rational AI, but you can fine-tune one. In **Settings** → **Fine-Tuning**, you pick a **Base model** and a **Dataset**, then start training. See [Fine-tuning](/concepts/Finetuning) and [Fine-tune a model](/operational-guides/fine-tune-a-model).
