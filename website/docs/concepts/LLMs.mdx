# Large language models (LLMs)

A **large language model (LLM)** is a model trained on very large amounts of text to read and write language. You talk to it in plain words, and the same model can answer a question, summarize a report, draft an email or write code without being reprogrammed for each task.

"Large" refers to the number of internal values, called parameters, that the model adjusts during [training](/concepts/Model-training). Today's models have billions of them. More parameters let a model capture more patterns, and also make it slower and more expensive to run.

## What an LLM can't do on its own

- It knows only what was in its training data, up to its [knowledge cutoff](/concepts/Knowledge-cutoff), and nothing about your organization.
- It reads a limited amount of text at once, its [context window](/concepts/Context-window).
- It can state wrong things fluently. See [Hallucinations](/concepts/hallucinations).

## In Rational AI

Chat and touchpoints use an LLM to write their answers. Models are added in **Settings** → **AI Model Registry**, either from a provider such as OpenAI or Anthropic or as an open-source model your installation runs itself. The registry's **Conversational model** is the workspace default, and each touchpoint can set its own **Default model**. See [AI Model Registry](/cr/settings/ai-model-registry).
