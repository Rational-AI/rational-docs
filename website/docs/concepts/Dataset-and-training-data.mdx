# Dataset and training data

**Training data** is the set of examples a model learns from. A **dataset** is a collection of those examples prepared for one purpose, such as teaching a model to answer in your support team's style.

A model learns the patterns in its data, including its mistakes and imbalances. If most examples are about one product line, the model answers best about that product line.

## What makes a good fine-tuning dataset

- **Relevant**: the examples look like the real questions the model gets in use.
- **Correct and consistent**: every answer is one you'd be happy to send, in the same format.
- **Varied**: it covers the range of cases, the awkward ones included, instead of the same question a hundred times.
- **Clean**: no duplicates, and no personal data you don't want the model to repeat.

## In Rational AI

A dataset is the training material for [fine-tuning](/concepts/Finetuning). You manage datasets in **Settings** → **Datasets**: create one **From file** (in Alpaca or ShareGPT format) or **From events**, which builds examples from past conversations in your workspace. See [Datasets](/cr/settings/datasets) and [Fine-tune a model](/operational-guides/fine-tune-a-model).

A dataset is not a [Knowledge](/concepts/Knowledge). A Knowledge holds the documents an assistant searches when it answers; a dataset holds the examples a model trains on.
