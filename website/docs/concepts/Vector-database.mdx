# Vector database

A **vector database** stores [embeddings](/concepts/Embeddings-chunks-and-annotations), the lists of numbers that represent the meaning of each passage, and finds the ones closest in meaning to a question.

An ordinary database finds rows by exact values, such as "orders where the total is over 100". A vector database finds passages by meaning: a search for "late deliveries" also finds "the shipment arrived two weeks after the due date".

## In Rational AI

Rational AI runs the vector database for you, so you never manage it directly. When you add content to a [Knowledge](/concepts/Knowledge), its embeddings are stored there, and [RAG](/concepts/RAG) searches them to find the passages for an answer. For exact values, assistants query the Knowledge's structured data instead.
