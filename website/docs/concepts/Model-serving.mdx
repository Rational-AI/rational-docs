# Model serving

**Model serving** is keeping a model running so that applications can send it requests and get answers back. Each request it answers is one [inference](/concepts/Inference).

## Where the model runs

- **At a provider.** A model from a provider such as OpenAI or Anthropic runs on the provider's machines. Rational AI sends each request through a [connector](/concepts/Connectors).
- **On your installation.** An open-source or fine-tuned model runs on hardware your installation controls. The running copy is the model's **deployment**.

A self-hosted model takes up its hardware only while it runs. You can keep it running so every request is answered at once, or let it release the hardware when idle, in which case the next request waits while the model starts again.

Speed, cost, and quality pull against each other. A larger model often answers better, but more slowly and at a higher cost.

## In Rational AI

You add models in **Settings** → **AI Model Registry** and deploy the self-hosted ones from the model's page. See [Deploy and run self-hosted models](/operational-guides/model-deployments). To see how fast and how expensive each model is in practice, use [Governance](/cr/Governance).
