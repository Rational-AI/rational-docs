# Context window

The **context window** is the most text a model can take into account in one request, measured in [tokens](/concepts/Tokens). It holds the [system prompt](/concepts/System-prompt), the passages retrieved from a Knowledge, the conversation so far, your question, and the reply. The model doesn't see anything that doesn't fit.

Each model has its own window size, and the reply shares it with everything you send. A very long input leaves less room for the answer.

## Why the limit matters

- **More text isn't better**: filling the window with loosely related material can bury the passage that answers the question.
- **Long conversations run out of room**: the earliest messages eventually no longer fit.
- **Cost and speed**: the model processes every token in the window on every request.

## In Rational AI

- A Knowledge doesn't send whole documents to the model. It splits them into [chunks and embeddings](/concepts/Embeddings-chunks-and-annotations), and [RAG](/concepts/RAG) sends only the passages that best match the question.
- When a chat gets too long, the assistant usually carries on from a summary of the earlier messages. Some touchpoints stop instead and offer **New conversation**. See [Keep going in a long conversation](/operational-guides/chat-experience#keep-going-in-a-long-conversation).
- A model's page in **Settings** → **AI Model Registry** shows its **Context length**.
