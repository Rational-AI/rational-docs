# Inference

**Inference** is running a model to get an answer. Every question you ask, every summary and every chat title a touchpoint generates is one inference. [Training](/concepts/Model-training) builds the model once; inference uses it on every request.

Inference doesn't change the model. The model reads your input, writes the answer, and keeps nothing. To change what a model knows, you [fine-tune](/concepts/Finetuning) it, or you put the information in the request, which is what [RAG](/concepts/RAG) does.

## In Rational AI

Every inference passes through Rational AI's gateway, which records it. [Governance](/cr/Governance) shows usage and cost per model and per [token](/concepts/Tokens), and how fast each model answers: **Average time to first token** (how long until the answer starts) and **Average tokens per second** (how fast it then appears). Where the model runs is covered in [Model serving](/concepts/Model-serving).
