# Reinforcement learning from human feedback (RLHF)

**Reinforcement learning from human feedback (RLHF)** is a training step that teaches a model which answers people prefer. A model trained only on text writes fluently, but it can't tell a clear and honest answer from an evasive or rambling one. RLHF adds that judgment.

## How it works

1. People compare two or more answers to the same question and pick the better one.
2. Those choices train a second model that predicts how much people would like an answer.
3. The language model is trained further to write answers that the second model scores highly.

People tend to rate agreeable answers highly, so a model trained this way can learn to tell you what you want to hear. See [Sycophancy](/concepts/Sycophancy).

## In Rational AI

RLHF happens at the model maker, before a model is released. The chat models you use in Rational AI have usually been through it, which is why they follow instructions. Fine-tuning in Rational AI works differently: it trains a model on example conversations from a dataset. See [Fine-tuning](/concepts/Finetuning).
