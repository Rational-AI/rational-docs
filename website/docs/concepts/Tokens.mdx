# Tokens

A **token** is the unit of text a model reads and writes. Before a model reads your message, the text is split into tokens, and the model writes its reply one token at a time.

A token is often a whole common word, or a piece of a longer one. One token is about four characters of English, so 1,000 tokens are roughly 750 words. Other languages often need more tokens for the same text, and each model splits text its own way.

## Why tokens matter

- **Limits**: the [context window](/concepts/Context-window) and the length of an answer are counted in tokens.
- **Cost**: providers charge per token, usually more for the tokens a model writes than for the ones it reads.
- **Speed**: a model writes token by token, so a longer answer takes longer.

## In Rational AI

[Governance](/cr/Governance) shows token usage and cost per model. On a touchpoint, **Maximum output tokens** caps how long an answer can be; see [Configure touchpoints](/operational-guides/configure-touchpoints).
