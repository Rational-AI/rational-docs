# Troubleshooting

Find your symptom below and follow the link to its fix. Each guide has a **Troubleshooting** table with the cause and what to check.

If your problem isn't listed, look the message up in [Error messages](/reference/error-messages), or search the docs for its exact text. For sizes, timeouts and counts, see [Limits and quotas](/reference/limits).

## Installation and operations

**[Back up and restore](/operational-guides/backup-and-restore#troubleshooting)**
- **Test destination** fails with *permission denied*
- A backup shows *failed*
- A component is *skipped*, or the backups list is empty

**[Rational AI Tunnel](/operational-guides/tunnel#troubleshooting)**
- The endpoint does not resolve, or resolves to an old IP
- Reachable on the local network but not from outside
- Certificate warning in the browser
- The endpoint never appears

**[License](/operational-guides/license#troubleshooting)**
- *The platform does not know this code*
- *The license does not verify*, or was issued for another installation
- A module stays hidden after an activation

## Agents

**[Create an agent](/operational-guides/create-an-agent#troubleshooting)**
- **Run now** is grayed out
- *"No text-generation model is available"* or *"The configured Agents default model is unavailable."*
- The agent says a tool is not available

**[Agent runs](/operational-guides/agent-runs#troubleshooting)**
- The run stays *Queued*
- The run ends *Failed* with a verification message, or *Timed out*
- *Stop* reports that cancellation was not confirmed

**[Agent computers](/operational-guides/agent-computers#troubleshooting)**
- *"Computer service was not found"* or *"did not respond in time"*
- The desktop shows *Disconnected*

## Models and the API

**[Deploy open-source models via API](/operational-guides/api/deploy-open-source-models#troubleshooting)**
- `404` on every call, or `409` on create or deploy
- A deployment is stuck in `provisioning` with `WaitingForCapacity`
- A deployment `failed` with `OutOfMemory` or `Crashed`

## Connectors and data sources

**[Google Drive](/operational-guides/integrate-data#troubleshooting)**
- A broken-link icon (**Missing authentication**) next to the connector
- Google shows *redirect_uri_mismatch* during sign-in
- Google shows *access blocked* or *app not verified*
- The file panel shows *Connection failed*
- The folder you want isn't in the file panel
- Syncs fail after working for some days

**[Amazon S3](/operational-guides/connectors/amazon-s3#troubleshooting)**
- The file panel stays on *No files to show yet*
- The file panel shows *Connection failed*
- The source syncs but some objects are missing
- **Automatic** isn't offered in **Sync settings**

**[Azure Blob Storage](/operational-guides/connectors/azure-blob-storage#troubleshooting)**
- The file panel stays on *No files to show yet*
- The first sync fails
- The sync error mentions authorization or a 403 status
- The sync error mentions the client secret

**[OneDrive and SharePoint](/operational-guides/connectors/onedrive-sharepoint#troubleshooting)**
- Microsoft shows *AADSTS50194* during sign-in
- Microsoft shows a redirect URI error during sign-in
- *"Tenant ID is required for application-permission connectors."*
- The file panel stays on *No files to show yet*
- The file panel shows *Connection failed*
- A broken-link icon (**Missing authentication**) next to the connector

**[Google Cloud Storage](/operational-guides/connectors/google-cloud#troubleshooting)**
- Google Cloud refuses to create a key for the service account
- The source fails with a permission error
- The source fails to read the key
- **Google Cloud Storage** isn't offered as a source type

**[Git repositories](/operational-guides/connectors/git#troubleshooting)**
- *"Enter an HTTPS repository URL without embedded credentials."*
- *"The Git credentials connector host must match the repository host."*
- The first sync fails with an authentication error
- The source keeps old files after you changed the branch

**[SQL databases](/operational-guides/connectors/sql-databases#troubleshooting)**
- **Test connection** is unavailable
- **Test connection** shows **Not connected**
- **Read-only account** shows *No: the account can write to the database*
- *"No SQL database connector yet: add one in the settings first."* in **New virtual database**
- *"The host must be a host name or an IP address…"*

**[HTTP addresses](/operational-guides/connectors/http#troubleshooting)**
- *"Enter a valid URL starting with http:// or https://"*
- *"Add at least one URL."*
- The sync fails for one address
- The Knowledge holds a login page instead of the file

**[RabbitMQ](/operational-guides/connectors/rabbitmq#troubleshooting)**
- *"The host must be a host name or an IP address, for example rabbitmq.example.com"*
- *"Enter the queue to consume."*
- *"Files can only be deleted after publishing when there is a result queue to publish to."*
- The source shows a failed status
- Messages stay in the queue
- Results come back with *"The message has no 'url' field with the file URL."*

**[Model providers](/operational-guides/connectors/model-providers#troubleshooting)**
- *"Could not list the provider models"* when you open **Model**, with *"… responded 401 Unauthorized"*
- *"Could not list the provider models"* with *"Could not reach …/models"*
- *"Enter an absolute URL including the scheme, e.g. https://api.example.com/v1"*
- *"Enter a single Google Cloud region, e.g. europe-west8 — not global or a multi-region such as eu"*
- *"Enter a Google Cloud project ID, e.g. my-project-123"*
- *"Could not get a Google access token for this backend"*
- A Vertex AI error that ends in *"responded 403 Forbidden"*
- *"Model already exists"*

**[Brave Search](/operational-guides/connectors/brave-search#troubleshooting)**
- The Brave Search extension card shows **Configuration needed**
- *"No connectors available"* in the connector field
- The assistant never searches the web
- Search tool calls fail

**[LinkedIn, Instagram and Facebook](/operational-guides/connectors/social-accounts#troubleshooting)**
- The network shows a redirect URI error during sign-in
- *"The login did not complete"*
- *"This account manages no page the app can publish to"*
- *"Could not connect this page: log in again"*
- The connector shows **Login expired** or **Reconnect soon**
- *"An error occurred while authenticating"* when you select **Add and authorize**

## Channels

**[Email](/operational-guides/connect-email#troubleshooting)**
- A mailbox that worked has stopped receiving mail
- **Connect** fails with an app password
- Mail arrives but gets no automatic reply

**[Microsoft Teams](/operational-guides/connect-teams#troubleshooting)**
- **Error while connecting the channel** after **Connect**
- The bot gets messages but never answers
- Nothing arrives in Conversations

**[Slack](/operational-guides/connect-slack#troubleshooting)**
- **Error while connecting the channel** after **Connect**
- Slack can't verify the **Request URL**
- A mention in a Slack channel gets no answer, or messages arrive but nobody answers

## Extensions

**[Build an extension](/operational-guides/build-an-extension#troubleshooting)**
- *"Package must contain exactly one extension root directory."* or *"Package root must be named '…'."*
- *"Unsupported file…"* when you upload the package
- *"Workflow '…' already exists and is not owned by this extension."*
- Your changes don't appear after a new upload
- A `${fieldName}` value reaches the server empty
- Synced metadata files appear as empty resources

**[Develop an extension](/operational-guides/develop-an-extension#troubleshooting)**
- *"File edits require development mode on this installation."*
- *"Development must preserve installed identity and version…"*
- *"Exit development mode before updating this extension."*
- `push` stops and asks you to pull

## Integrations

**[Graphify MCP server](/operational-guides/external-graphify-mcp#troubleshooting)**
- The server can't reach Rational AI, or authentication fails
- `query_graph` returns nothing, or the tool asks for a `knowledgeId`
- `uv` fails to start the server
- *"graphify query failed"*

**[User details panel](/operational-guides/personalize-user-details#troubleshooting)**
- Only the built-in fields show, or a widget is empty or never appears
- Widgets disappeared after an update
- The user's name changed after an update
