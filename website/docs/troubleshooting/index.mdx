# Troubleshooting

Find your symptom below and follow the link to its fix. Each guide has a **Troubleshooting** table with the cause and what to check.

If your problem isn't listed, look the message up in [Error messages](/reference/error-messages), or search the docs for its exact text. For sizes, timeouts and counts, see [Limits and quotas](/reference/limits).

## Installation and operations

**[Back up and restore](/operational-guides/backup-and-restore#troubleshooting)**
- **Test destination** fails with *permission denied*
- A backup shows *failed*
- A component is *skipped*, or the backups list is empty

**[Rational AI Tunnel](/operational-guides/tunnel#troubleshooting)**
- The endpoint does not resolve, or resolves to an old IP
- Reachable on the local network but not from outside
- Certificate warning in the browser
- The endpoint never appears

**[License](/operational-guides/license#troubleshooting)**
- *The platform does not know this code*
- *The license does not verify*, or was issued for another installation
- A module stays hidden after an activation

## Agents

**[Create an agent](/operational-guides/create-an-agent#troubleshooting)**
- **Run now** is grayed out
- *"No text-generation model is available"* or *"The configured Agents default model is unavailable."*
- The agent says a tool is not available

**[Agent runs](/operational-guides/agent-runs#troubleshooting)**
- The run stays *Queued*
- The run ends *Failed* with a verification message, or *Timed out*
- *Stop* reports that cancellation was not confirmed

**[Agent computers](/operational-guides/agent-computers#troubleshooting)**
- *"Computer service was not found"* or *"did not respond in time"*
- The desktop shows *Disconnected*

## Models and the API

**[Deploy open-source models via API](/operational-guides/api/deploy-open-source-models#troubleshooting)**
- `404` on every call, or `409` on create or deploy
- A deployment is stuck in `provisioning` with `WaitingForCapacity`
- A deployment `failed` with `OutOfMemory` or `Crashed`

## Data sources

**[Integrate data from Google Drive](/operational-guides/integrate-data#troubleshooting)**
- A red broken-link icon next to the connector
- The file panel lists no folders
- Google shows a redirect URI error during sign-in

## Channels

**[Email](/operational-guides/connect-email#troubleshooting)**
- A mailbox that worked has stopped receiving mail
- **Connect** fails with an app password
- Mail arrives but gets no automatic reply

**[Microsoft Teams](/operational-guides/connect-teams#troubleshooting)**
- **Error while connecting the channel** after **Connect**
- The bot gets messages but never answers
- Nothing arrives in Conversations

**[Slack](/operational-guides/connect-slack#troubleshooting)**
- **Error while connecting the channel** after **Connect**
- Slack can't verify the **Request URL**
- A mention in a Slack channel gets no answer, or messages arrive but nobody answers

## Extensions

**[Build an extension](/operational-guides/build-an-extension#troubleshooting)**
- *"Package must contain exactly one extension root directory."* or *"Package root must be named '…'."*
- *"Unsupported file…"* when you upload the package
- *"Workflow '…' already exists and is not owned by this extension."*
- Your changes don't appear after a new upload
- A `${fieldName}` value reaches the server empty
- Synced metadata files appear as empty resources

**[Develop an extension](/operational-guides/develop-an-extension#troubleshooting)**
- *"File edits require development mode on this installation."*
- *"Development must preserve installed identity and version…"*
- *"Exit development mode before updating this extension."*
- `push` stops and asks you to pull

## Integrations

**[Graphify MCP server](/operational-guides/external-graphify-mcp#troubleshooting)**
- The server can't reach Rational AI, or authentication fails
- `query_graph` returns nothing, or the tool asks for a `knowledgeId`
- `uv` fails to start the server
- *"graphify query failed"*

**[User details panel](/operational-guides/personalize-user-details#troubleshooting)**
- Only the built-in fields show, or a widget is empty or never appears
- Widgets disappeared after an update
- The user's name changed after an update
