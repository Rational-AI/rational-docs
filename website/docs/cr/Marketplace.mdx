# Marketplace

**Marketplace** is the catalog of ready-made solutions you can install into your workspace. A solution sets up a complete use case in one step. Depending on the solution, it creates a Knowledge with its collections and views, example records, reminders, agents, workflows, tools and skills, BI dashboards and reports, and a website widget.

Each solution is an [extension](/operational-guides/manage-extensions) underneath, and it is installed the same way as the extensions under **Settings** → **Extensions**. The difference is where you manage it: you install, update and uninstall a solution from its page in the Marketplace.

## Who can use it

The **Marketplace** tab is in the top navigation for every signed-in user, whatever your license includes. What you can do there depends on the **Extensions** row of your role (see [Manage roles and users](/operational-guides/roles-and-users)):

| Action | What your role needs |
| :----- | :------------------- |
| Browse the catalog and read solution pages | Nothing beyond signing in. |
| Install a solution | **Create** on **Extensions**. Without it, you see **Ask an admin** instead of **Install**, which sends your request to the administrators. |
| See the status of an installed solution, update it, restore an earlier version, or uninstall it | **Update** on **Extensions**. |

## Browse the catalog

Select **Marketplace** in the top navigation. The page has:

* A search box in the header, which covers the names, descriptions, and use cases of the solutions.
* A **Featured** solution, when Rational AI features one, with a **See the solution** link.
* **Browse by use case**: tiles for the use cases with the most solutions.
* A side panel to narrow the list: **All solutions**, **New and updated** (published or updated in the last 30 days), **Installed**, and the filters **By industry**, **By use case**, and **Includes**.
* The results, which you sort by **Newest**, **Recently updated**, **Name A to Z**, or **Installed first**.

Each card shows a solution's name and what it brings, and its state when it is already in your workspace, for example **Installed** or **Update available**.

## The solution page

Select a card to open the solution's page. Before you install, it is organized in **Overview**, **What it installs**, **Setup after install**, and **Versions**, so you can see exactly what the solution creates.

Once the solution is installed, the same page becomes its status page. It shows a **Setup** checklist when the solution has setup steps, then **Overview**, **Components** (each part of the solution with its state), and **Versions**. **More actions** holds **Check for updates**, **Version history**, and **Uninstall…**, plus **Restart setup** when the solution has setup steps and **Pause all agents** while its agents are active.

For every step, from installing to uninstalling, see [Install solutions from the Marketplace](/operational-guides/marketplace).
