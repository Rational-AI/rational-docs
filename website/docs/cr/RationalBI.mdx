# BI

**BI** is where you build dashboards and written reports from the data already in Rational AI. Describe the charts you want and Rational AI builds the dashboard, or lay it out by hand. Dashboards can refresh while they are open, and reports turn one or more dashboards into a summary you can send.

<video className="doc-video" controls preload="metadata" aria-label="Walkthrough of BI" poster="/img/videos/rational_bi.jpg" src="/videos/rational_bi_eng.mp4" />

Your work is organized into **projects**. A project covers one reporting area or audience, for example *Sales Reporting*, and sets which data sources and Knowledges its dashboards can query and which models generate its charts and reports. Inside a project you keep **dashboards** (grids of charts, headings, text and dividers) and **reports** (written summaries generated from one or more dashboards).

## Prerequisites

Before you start, make sure you have:

- **The BI module in your license.** The **BI** tab appears in the top bar only when the [license](/operational-guides/license) includes it.
- **Permission to use BI.** An administrator grants it on your role in **Settings** → **Roles**. To open the **BI** page, your role needs the **BI projects** row plus **Dashboards** or **Reports**. To build dashboards and reports, it needs **Create** and **Update** on **BI projects**, **Dashboards** and **Reports**; see [Grant access to Rational BI](/operational-guides/roles-and-users#grant-access-to-rational-bi).
- **Data to chart.** A dashboard can only query what its project can reach: a [data source](/operational-guides/configure-sources) or a [Knowledge](/operational-guides/create-knowledge).
- **A model** in the [AI Model Registry](/operational-guides/ai-model-registry-features) for the project to use when it generates charts and reports.

## Find your way around

Open BI by selecting **BI** in the top navigation bar. The first thing you see is your list of projects. **Settings** → **Rational BI** is where you configure projects, not where you build dashboards.

| Where | What you find there |
|-------|---------------------|
| **BI** → project list | Every project you can see. **New** takes you to **Settings** → **Rational BI** to create one. |
| Project → **Dashboards** | The project's dashboards. **New dashboard** (or **+** next to **Recents**) starts one, with AI or by hand. |
| Project → **Reports** | The written summaries. **+** next to **Reports** generates a new one. |
| Dashboard → **Chat** | The AI panel for adding or changing charts on an existing dashboard. |
| Dashboard → **Filters** | The dashboard's filters: lists of values or date ranges that narrow every chart that uses them. |
| Dashboard → **Actions** | **Edit**, **Auto-refresh**, **Auto layout** (moves widgets up to close empty gaps), **Download** and **Delete**. |
| **Settings** → **Rational BI** → project | **Settings** (name and description), **Sources** (what it can query), **Models** (what generates its charts and reports), **Tools** (what its AI chat can use) and, for administrators only, **Access** (who sees each table or view). |
| **Settings** → **Rational BI** → **BI defaults** | The **Chat model**, **Model template prompt** and **Default tools** that new projects start with, and the **Report starter prompt** used for every report. Changing them needs the **BI defaults** permission. |

## How the pieces fit

1. **Create a project** for one reporting area and point it at its sources and Knowledges.
2. **Generate a dashboard** with AI from a description, then refine it in **Chat** or by hand.
3. **Tune each chart**: its type, the data it queries, its colors and its legend.
4. **Keep it current** with an auto-refresh interval, so an open dashboard shows new numbers without regenerating anything.
5. **Write a report** from one or more dashboards when you need to say what the numbers mean.
6. **Show the dashboard where people work**, inside a Knowledge as a custom view.

## Dashboards

You usually start a dashboard with AI and then refine it:

* **Generate it with AI:** in a project, select **New dashboard** → **Generate with AI** and describe the dashboard you want in plain language. Rational AI builds it for you. Later, open **Chat** on the dashboard to add or change charts.
* **Lay it out by hand:** select **Actions** → **Edit**, then drag widgets around the grid and resize them from the corner grip. The sidebar's **Sections** tab adds structure:

| Widget | What it is for |
|--------|----------------|
| **Title** | A heading from **Heading 1** to **Heading 4**, so a long dashboard reads as sections. |
| **Free text** | A paragraph of explanation next to the numbers. |
| **KPI card** | One headline number with its label. It is backed by a query, so it refreshes like a chart. |
| **Graphs** | A chart. |
| **Tables** | The data behind one of the dashboard's charts, shown as a table. |
| **Divider** | A horizontal rule between sections. |
| **Spacer** | Empty space of a height you choose, to separate blocks without a line. |

The sidebar's **Settings** tab holds what applies to the whole dashboard, such as **Global colors**.

### Charts

Select a chart to open **Chart settings**:

| Setting | What it controls |
|---------|------------------|
| **Chart type** | Bar, line, area, scatter, pie, donut, radar or **Geographic map**. |
| **Data source**, **SQL Query** and **Available tables** | What the chart queries. |
| **Colors** and **Legend position** | How it looks. |
| **Advanced (Spec)** | The underlying chart specification, for anything the controls don't expose. |

:::note[Geographic maps]
A **Geographic map** colors each region by its value. Two maps are available today: **US states** and **Italian regions**. You don't upload any map files: if your data has a column of state or region names, Rational AI recognizes them and draws the right map. You can also ask for one in the chat, for example *"sales by region on a map of Italy"*.
:::

## Keep the numbers current

A saved dashboard shows the data captured when its charts were generated. Select **Actions** → **Auto-refresh** and choose an interval: **Off** (the default), **30 seconds**, **1 minute**, **5 minutes** or **15 minutes**. While the dashboard is open, Rational AI re-runs each chart's saved query on that interval and updates the results in place.

:::note[Refreshing is not regenerating]
No model is involved in a refresh, so it costs no model calls. If a refresh fails, the dashboard keeps the last good data instead of interrupting whoever is looking at it.
:::

## Reports

A dashboard answers "what do the numbers look like"; a report answers "what should we take from them". In a project, select **+** next to **Reports**, choose one or more dashboards, describe what the report should cover and select **Generate with AI**. Review the draft and select **Create** to save it. Then use the report's **Chat** to ask for a different emphasis, a shorter summary or an extra section, or **Edit** to rearrange it. Its **Actions** menu holds **Refresh data**, **Duplicate**, **Auto layout**, **Download** (PDF, CSV or Excel) and **Delete**.
