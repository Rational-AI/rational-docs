# Datasets

Datasets are the curated collections of examples you use to fine-tune models in Rational AI. Each dataset stores its entries in a standard training format, keeps a full version history as you add more data, and can be downloaded or reused across fine-tuning jobs. Use this section to build, organize and maintain the training data that powers your custom models.

## Supported formats

When you create a dataset you choose the format its entries follow. The structure of any file you upload must match the selected format:

| Format | Description |
|--------|-------------|
| **Alpaca** | Instruction-style entries, each pairing an instruction (and optional input) with the expected response. Best for single-turn, task-oriented fine-tuning. |
| **ShareGPT** | Conversation-style entries, each containing a list of turns labeled by role (for example, `human`, `gpt`). Best for multi-turn, chat-oriented fine-tuning. |

## Create a dataset

Select **New** and choose how you want to build the dataset:

* **From file**: upload an existing JSON file of training entries.
* **From events**: generate a dataset from conversational events already captured in the platform.
* **From recorded traffic**: build a dataset from the model requests Rational AI recorded, including system prompts and tool calls. See [Fine-tune a model](/operational-guides/fine-tune-a-model#from-recorded-traffic).

### Create from file

* Choose **From file**
* Enter a **Name** and an optional **Description**
* Pick the **Format** (Alpaca or ShareGPT) that matches your file
* Drag a file into the upload area, or select **Click or drag here your dataset** to select one from your computer
* Select **Save**

The uploaded file must follow the structure of the selected format, otherwise the import is rejected.

### Create from events

Choose **From events** to assemble a dataset from conversations and interactions that have already taken place in Rational AI. Enter a **Name**, an optional **Description** and an optional **Prompt**, then under **Select event types** choose which kinds of events to extract, and select **Save**.

## Work with a dataset

Select a dataset row to open its detail view. The page shows the dataset name, its description, its current version and the number of **Examples**. Select an example in the list to read it as **Example #** followed by its number. Its menu offers **Edit example**, which opens it as JSON, and **Remove example**.

### Manage versions

The version chip next to the dataset name (for example, **v1**) shows its current version. It goes up each time you append, edit or remove examples. The page shows the current version only.

### Append new entries

Use **Append new entries** (from the row menu or the detail view) to add more examples to an existing dataset. Appending entries produces a new version.

## Manage datasets

Open the options menu (the three vertical dots) on any dataset row, or the menu in the detail view, to access the following actions:

| Action | Description |
|--------|-------------|
| **Append new entries** | Add more entries to the dataset, creating a new version. |
| **Rename** | Change the dataset's name. |
| **Duplicate** | Copy the dataset. Only in the list's row menu. |
| **Download** | Export the dataset to a JSON file in its current format. |
| **Delete** | Permanently remove the dataset. |

## Browse datasets

The Datasets list shows every dataset with columns for **Name**, **Format**, **Entries** (the number of training examples), **Created at**, **Updated at** and **Current version**.

* **Search**: use the search box to filter datasets by name.
* **Sort**: select the arrows next to any column header to sort the list by that column.
