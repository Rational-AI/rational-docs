# Extensions

Extensions add new capabilities to Rational AI. Depending on the one you install, an extension can give your agents new **tools** to use in a conversation (such as fetching a web page, querying a database or searching the web), **skills** they can draw on, a **channel** for users to message the assistant (like Telegram), a **source** your Knowledge bases sync files from, or a **workflow** that processes incoming files. The [Marketplace](/operational-guides/marketplace) solutions are extensions too: installing one can also create a Knowledge base with its views and records, agents, BI dashboards and a website widget. Use this section to install extensions from the catalog or from your own package files, enable or disable them, configure their settings and review what each one provides. To keep the ones you have current, see [Update and roll back extensions](/operational-guides/extension-updates).

## Browse installed extensions

The Extensions page has three views: **Installed**, **Updates** and **Browse**. **Installed** lists every installed extension as a card with its name, icon and version, and counters for the tools, sources and channels it provides. A card also shows **Configuration needed** when its server still needs parameters, and **Update available** or **Review required** when a newer release exists.

* **Search**: use the search box to filter extensions by name.
* **Select**: select a card to open its details: an **Overview** of what it provides (each tool with a short description), **Release notes**, **Versions** and **Activity**.

## Add and configure an extension

**Install** opens the extensions you can install, marked **Rational AI catalogue** or **Local**. **Add private extension** installs a package from a file. An extension that still needs values shows **Configuration needed**. For the steps, see [Manage extensions](/operational-guides/manage-extensions).

Administrators see a **Development** tab on an installed extension, to edit its files. Updates pause while development mode is on.

## Enable or disable an extension

Use the switch on each extension card to turn it on or off. A disabled extension stays installed and keeps its configuration, but its tools are not available to agents until you turn it back on. Use it to take an extension out of service for a while without uninstalling it.

## Manage an extension

With an extension selected, **Update policy** sets how updates reach it: **Compatible updates automatically**, **Notify me** (the default) or **Pinned**. When an update is available, an **Update** button appears next to the version.

The options menu (the three vertical dots) holds:

| Action | Description |
|--------|-------------|
| **Settings** | View and edit the extension's configuration (for example, credentials or connection details). Unavailable when there is nothing to configure. |
| **Refresh remote tools** | Read the tool list again from the extension's remote MCP servers. Only for extensions with a remote server. |
| **Update to latest version** | Move the extension to the newest release. Unavailable when it is already up to date. |
| **Install a different version** | Pick another published release, older or newer. |
| **Roll back** | Return to the last release that worked. Unavailable when there is none. |
| **Uninstall** | Remove the extension, its MCP servers, its configurations and its tools. Touchpoints that used its tools keep working without them. |

For what a compatible update is and how to roll back, see [Update and roll back extensions](/operational-guides/extension-updates).
