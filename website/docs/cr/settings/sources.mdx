# Sources

A source is a connection to an external system that supplies data to Rational AI, such as an Amazon S3 bucket or a Google Drive folder. Sources keep your content in sync (on change, on a schedule, or on demand), so the [Knowledge](../Knowledge.mdx) module, touchpoints and Rational BI projects they are attached to work from up-to-date material. Use this section to add sources, configure how often they sync and monitor the result of each synchronization.

## Browse sources

The Sources page lists every configured source as a card with its name and provider icon. Use the **search** box to filter sources by name, and select a card to open its details.

The details panel shows:

* **Description**: an editable note describing the source.
* **Provider**: the underlying provider (for example, AWS or Google Drive).
* **Sync mode**: how synchronization is triggered: *Automatic*, *Periodic* or *Manual*.
* **Schedule**: when the source syncs (for example, *Every hour at 30 minutes*).
* **Next scheduled sync**: the date and time of the upcoming sync. Not shown for an *Automatic* source, whose two-minute check for changes is not a sync.
* **Status**: the current sync state (for example, *Synced*).
* **Last sync at** and **Outcome**: when the latest sync ran and how it ended. The options menu opens the full history (**Processing log**).

After editing fields such as the description, use **Save** to apply changes or **Undo** to discard them.

## Add a source

Select **Add** and fill in the **Add new source** dialog:

| Field | Description |
|-------|-------------|
| **Name** | A name to identify the source. |
| **Description** | Optional notes about the source. |
| **Type** | The kind of source and, for types that need one, the [connector](connectors.mdx) that holds the credentials used to access it, picked in one field: each type lists its connectors under it. Types include Amazon S3, Azure Blob Storage, Google Cloud Storage, Google Drive, OneDrive, HTTP, Git repository, RabbitMQ queue and sources contributed by extensions. A type whose connector doesn't exist yet isn't listed. |

Choosing a type reveals type-specific options under **Advanced settings** (for example, the **Bucket** for an Amazon S3 source). For types whose files you pick, a file panel lists the folders and files the connector can reach: filter them, select what to sync or use **Select all**, and drag the divider to resize the panel. Select **Add** to create the source.

## Synchronization settings

Each source has its own synchronization settings, opened with **Sync settings** in the options menu, that control when it runs and what happens to derived content when items are removed at the origin.

  src={require('/img/screens/sync-settings.png').default}
  style={{
    border: '1px solid #e4e4e7',
    borderRadius: '10px',
  }}
  alt="The Sources page with the Synchronization settings dialog open, showing sync mode, schedule and on-delete behavior"
/>

| Setting | Description |
|---------|-------------|
| **Sync mode** | How synchronization is triggered. **Automatic** checks the source every two minutes and syncs only when something changed (Git, Google Drive, OneDrive and HTTP sources only). **Periodic** syncs on the schedule below. **Manual** syncs only when you select **Sync now**. |
| **Sync schedule** | How often the source syncs: **Every number of minutes** (1 to 59), **Every number of hours** (1 to 23), **Every hour**, **Every day**, **Weekly** or **Monthly**, with the minute, time or weekday when applicable. |
| **On delete** | What happens to the knowledge base when an item is removed from the source: **Cascade delete** keeps the knowledge base strictly aligned with the source by deleting the derived files too, while **Keep** retains those files to prevent data loss from accidental deletions. |

## Manage a source

Open the options menu (the three vertical dots) in the details panel to:

| Action | Description |
|--------|-------------|
| **Sync now** | Run a sync immediately, whatever the schedule or retry wait. For a RabbitMQ queue, start consuming the queue; **Stop sync** stops it. |
| **Sync settings** | Change the sync mode, schedule and on-delete behavior. |
| **Processing log** | Open the **Data processing log**: live sync activity and the history of recent runs. |
| **Edit** | Update the source's name, description, connector or advanced settings. |
| **Delete** | Remove the source from the platform. The files imported from it into any Knowledge are deleted with it. |

:::note
After a failed sync, scheduled syncs wait before retrying: 2 minutes, doubling with each consecutive failure up to one hour, and reset by the next success. **Sync now** always runs immediately. See [Configure data sources](/operational-guides/configure-sources#what-happens-when-a-sync-keeps-failing).
:::
