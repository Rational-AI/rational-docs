# Chat

**Chat** is the page the Control Room opens on: the workspace where the people in your organization talk to Rational AI. Every signed-in user can use it. A chat starts with the **workspace assistant** (**Rational Chat** in the picker), or with any [touchpoint](./settings/touchpoints.mdx) you can use, and the assistant answers with the model, knowledge and tools that touchpoint has. Use it to ask questions about your data, draft documents, test how a touchpoint behaves, and pick up earlier chats. It is not where your customers chat: they reach touchpoints through their channels, and staff review those conversations in [Conversations](./Conversations.mdx). For step-by-step instructions, see [Use Chat](/operational-guides/chat-experience).

## Start a chat

Open the **Chat** section from the top navigation bar of the Control Room. To begin:

* **Choose a touchpoint** by selecting the assistant's name at the top of the page. **Rational Chat**, the workspace assistant, comes first, followed by the enabled touchpoints you can use. This sets which assistant you're talking to, along with the knowledge and data sources it can reach.
* **Ask a question**, or select one of up to three **suggested questions** below the composer. The suggestions are defined per touchpoint.

The assistant replies in the thread, drawing on its connected sources. While it works, a single line above the answer summarizes what it's doing (reasoning, searching your knowledge, using tools or running a [skill](/operational-guides/agent-skills)), and you can open it afterwards to see every step.

## The composer

One message box serves both the new-chat screen and every conversation:

| Control | What it does |
| :------ | :----------- |
| **+** (*Open tools menu*) | Attach files and photos, choose **Knowledge bases**, switch on **Web search**, **Deep Research**, **Canvas**, **Voice conversation** or **Advanced mode**, pick a **Skill**, and turn memory off for a new chat. Each active option shows as a removable chip. **Knowledge bases**, **Web search** and **Deep Research** work only with the workspace assistant. |
| **`/`** | Typed in an empty message, lists the touchpoint's skills; the one you pick becomes a chip at the start of your message. |
| **Model and reasoning** | Shows the model and reasoning level in use. The model can be changed only in your own chats with the workspace assistant; the reasoning level wherever the touchpoint allows it. |
| **Mic** | Dictate a message (or hold **Ctrl+Shift+D**); the arrow beside it sets the **Audio language**. |
| **Send** / **Stop generating** | Send your message, or stop an answer that is still being written. |

**Advanced mode** expands each reply's steps with their technical detail, such as the phases of a knowledge search. Administrators also see the arguments and raw output of each tool call; other users see only the tool names.

## The sidebar

The sidebar keeps your chats within reach. You can collapse or expand it with the toggle at the top.

* **New chat** starts a fresh conversation with the workspace assistant.
* **Search** finds an earlier chat by its content.
* The list shows your chats, each with an automatic title, grouped into **Today**, **Yesterday**, **Previous 7 days** and **Older**. Administrators, and roles that can see all conversations, see every chat in the workspace. Open the options menu (three dots) on a chat to **Rename chat** or **Delete** it.

Select a chat's title at the top of the page to **Rename** it, **Copy link to chat**, **Export chat** as a JSON file, manage its **Memory**, or **Delete** it. Renaming and the **Memory** switch are for administrators.

## Working in a conversation

Each thread shows your messages alongside the assistant's replies in order. Under each answer you can copy it, rate it, regenerate it, move between its versions, and open the **Sources** panel listing the knowledge resources and web pages it used. Its **⋯** menu adds **Read aloud**, **Verify response** (which highlights supported, unsupported and disproven sentences and opens **Response verification**) and **Branch into a new chat**. When an answer stops early, a short message says why, usually with **Regenerate response**.

Documents the assistant creates open in the **Canvas** panel beside the chat, where you can edit Office files, download them (including as PDF), rename them, or **Save to knowledge**.

Every chat is also a conversation record, so people with access to [Conversations](./Conversations.mdx) can review, label and audit it.
