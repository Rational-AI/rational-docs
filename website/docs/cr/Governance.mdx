# Governance

The **Governance** area of the Control Room reports on how your AI is used and what it costs, and it holds the decisions that control which applications may call your models. Select **Governance** in the top navigation bar to open it. The area is restricted to administrators.

This page is a reference for the area's layout. For step-by-step tasks, see [Monitor usage, cost, and audit logs](/operational-guides/governance) and [Govern AI applications](/operational-guides/govern-ai-applications).

## Tabs

The area has five tabs. Each tab opens with a heading that names the period it reports on, for example *Oct 3 – Nov 2*.

| Tab | What it shows |
|---|---|
| **Overview** | A **Needs attention** summary, the headline totals (led by **Total costs**), a featured chart, **Cost composition**, **Governance health**, and the **Top applications** by requests. |
| **Usage** | Charts over time, grouped by topic. A switch selects **APIs** or **Conversational** traffic. |
| **Applications** | The inventory of applications seen in proxy traffic or registered by hand, with their status, risk tier, owner, environment, tags, and usage. |
| **Audit log** | One row for each model request that went through the proxy. A switch at the top shows the **Workflow runs** instead. |
| **Costs** | The cost ledger: rates, booked costs, amortised assets, and node pools, plus the **Reported in** currency. |

:::note[Old dashboard and audit log links still work]
Before the redesign, Governance had a **Dashboard** tab and an **Audit Log** tab. Bookmarks and shared links to those tabs still open the right place: a link to the Dashboard opens **Overview**, and a link to the Audit Log opens the request list in **Audit log**.
:::

## Overview

* **Needs attention** appears only when something needs action. It is collapsed to a single line that counts the problems. Select **Show** to list them, each with a button that takes you to the fix:
  * applications that are not governed yet (**Register apps**),
  * requests that have no price (**Set prices**),
  * an error rate high enough to flag (**See requests**),
  * workflow runs that failed or timed out (**See the runs**).
* **Total costs**, **Total inferences**, **Total input tokens**, and **Total output tokens** summarize the period. Costs are shown in the reporting currency.
* **Cost composition** lists the costs recorded for the period by source, with their total. **Open the cost ledger** opens the **Costs** tab.
* **Governance health** shows **Cost coverage**, **Unpriced requests**, **Error rate**, and **Cache hit rate**.
* **Top applications** lists the busiest applications by requests. **View all** opens the **Applications** tab.
* **Provider subscriptions**, at the top right, opens the subscriptions of your connectors in **Settings** → **Connectors**.

## Usage

The **Usage** tab holds every chart. Choose the traffic type at the top:

| Type | Chart groups |
|---|---|
| **APIs** | **Volume** (tokens and inferences), **Speed** (tokens per second, time to first token), and **Unit economics** (costs, cost per inference, cost per model). |
| **Conversational** | **Engagement** (active users, active conversations, user messages) and **Quality** (topics and sentiment). |

## Applications

The inventory has a status switch (**All**, **Approved**, **Pending review**, **Blocked**, **Unregistered**, each with a count) and a search box that matches name, key, owner, or tag. Each row has an actions menu: **Edit** or **Register**, **See its requests**, **Copy key**, and **Delete**. **Register application** and **Edit** open the application in a panel docked beside the list.

A **Blocked** application and an application with the **Unacceptable** risk tier are refused. See [Govern AI applications](/operational-guides/govern-ai-applications) for what each setting does.

## Audit log

The request list has an outcome switch: **All**, **Errors**, or **Unpriced**. Its columns are:

| Column | Description |
|---|---|
| **Timestamp** | When the request was made. |
| **Model** | The model that handled it. |
| **Application** | The application the request was attributed to, or **Direct** when it carried none. |
| **Tokens** | Input tokens → output tokens. |
| **Costs** | The cost of the request, in the reporting currency. |
| **TTFT** | Time to first token. |
| **E2E latency** | Total time from the request to the full response. |
| **Speed** | Generation speed in tokens per second. |
| **Finish** | How the response ended: **Completed**, **Truncated**, **Tool calls**, or **Filtered**. |

Select a row to open the request in a panel docked beside the list. The panel shows the status and operation, the source (model, application, touchpoint, user, session), usage and cost, performance, and the request and response bodies when the model's tracing recorded them.

**Workflow runs** lists each run with **Started**, **Status**, **Workflow**, **Duration**, and **Failure**.

**Export** downloads the rows that match the current filters as a CSV.

## Costs

The **Costs** tab is titled **Cost ledger**. It shows where costs come from (**Infrastructure runtime**, **Facility and operations**, **Amortised assets**, **Provider subscriptions**), with **Total costs** and **Cost coverage**, and has four sections: **Rate history**, **Booked costs**, **Amortised assets**, and **Node pools**. **Reported in**, at the top right, sets the currency that every governance cost is shown in.

## Filters

Select **Filters** in the toolbar to open the **Filters** panel. The panel lists only the filters that apply to the open tab:

| Filter | Tabs | Options |
|---|---|---|
| **Touchpoints** | Overview, Usage, Audit log | Up to four touchpoints. Not available while a model is selected. |
| **Models** | Overview, Usage, Audit log | Up to four models. Not available while a touchpoint is selected, or for conversational usage. |
| **Applications** | Overview, Usage, Audit log | Up to four applications. Not available for conversational usage. |
| **Period** | Every tab except Costs | *Last 24 hours*, *Last 7 days*, *Last 30 days* (default), *Last 3 months*, *Last 6 months*, *Last year*, *All*. |

Changes take effect only when you select **Apply**. **Clear** resets the filters of the open tab. The **Filters** button shows how many filters are active.
