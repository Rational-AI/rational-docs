# Manage channels

Channels define how Rational AI produces its draft responses. This guide covers naming a channel uniquely and the fields you'll see in the channel create and edit dialog.

<Admonition type="info" icon="📖" title="WHAT IS A CHANNEL?">
A channel groups the settings used to generate draft responses, including its provider and the number of drafts to produce. Channels are referenced by name elsewhere in the product (for example, when configuring touchpoints), so a clear, unique name keeps them easy to tell apart.
</Admonition>

## Prerequisites

Before you start, make sure you have:

- **Administrative access:** an account with channel management privileges.
- **A channel provider (extension):** the provider is selected when you create a channel and is fixed afterwards, so confirm the right one before creating.

## Create a channel

1. Go to **Settings** → **Channels** and select **New channel**.
2. Enter a **name** for the channel. The name must be unique across all channels (see the note below).
3. Select the channel **Extension** (provider). This field is only available when creating a channel.
4. Set the **Number of drafts**. This field defaults to `2`, with the placeholder `Number of drafts...`. Adjust it if you want the channel to generate a different number of drafts.
5. Save the channel.

<Admonition type="note" icon="📝" title="CHANNEL NAMES MUST BE UNIQUE">
Each channel name must be unique. If you enter a name that another channel already uses, the channel is not saved and an error appears under the **name** field. Matching is case-sensitive and exact, so `Support` and `support` are treated as different names.
</Admonition>

## Edit a channel

1. Go to **Settings** → **Channels** and open the channel you want to change.
2. Update the **name** or **Number of drafts** as needed.
3. Save your changes.

When editing, the **provider** field is not shown. A channel's provider is fixed at creation and cannot be changed afterwards. As with creating a channel, the **name** must remain unique; renaming a channel to a name already used by another channel is rejected with a field-level error under the **name** field.

## Result

Your channel is saved with a unique name, a fixed provider chosen at creation, and a defined number of drafts (defaulting to `2`). Because each name is guaranteed to be unique, channels stay easy to identify wherever they're referenced across the product.
