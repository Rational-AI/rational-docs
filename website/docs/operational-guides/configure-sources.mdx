# Configure data sources

A source defines which external files Rational AI syncs, and when. You attach it to a [Knowledge](/operational-guides/create-knowledge), a touchpoint, or a Rational BI project, and each Knowledge then processes the synced files in its own step. Some source types are built in; others come from installed [extensions](/operational-guides/manage-extensions). Each built-in type has a setup page, listed in [Pick a source type](#pick-a-source-type).

## Prerequisites

- **The Knowledge module in your license:** **Sources** sits in the Knowledge section of **Settings** and is hidden without it.
- **Rights on sources:** **Create**, **Update** or **Delete** on the **Sources** row of your role, for the changes you want to make. See [Manage roles and users](/operational-guides/roles-and-users).
- **Somewhere to attach the source:** a Knowledge (see **Settings** → **Knowledge**), a touchpoint or a Rational BI project.
- **The relevant extension installed** when configuring an extension-contributed source (see **Settings** → **Extensions**).

## Choose when a source syncs

1. Go to **Settings** → **Sources** and select the source.
2. Open the **⋮** menu and select **Sync settings**.
3. In **Sync mode**, choose one of:

| Option | When to use it |
|--------|----------------|
| **Automatic** | The content changes at unpredictable times and you want changes picked up within a couple of minutes. Rational AI checks the source every two minutes and syncs only when something changed, processing again only what changed. Available for **Git**, **Google Drive**, **OneDrive**, and **HTTP** sources. |
| **Periodic** | You want syncs at fixed times, for example every night or once a week. Set the **Sync schedule** that comes with it: **Every number of minutes** (1 to 59), **Every number of hours** (1 to 23), **Every hour**, **Every day**, **Weekly** or **Monthly**. |
| **Manual** | You want to decide each time. The source syncs only when you select **Sync now**. |

4. Choose the **On delete** behavior, then select **Save**:
   - **Cascade delete**, the default: a file deleted at the source is deleted from every Knowledge that imported it, with everything derived from it.
   - **Keep**: files stay in the Knowledge after they're deleted at the source, which protects against accidental deletions.

:::note[Automatic only appears for sources that can report changes]
**Automatic** needs a source that can say *"nothing changed"* in a single call. Object stores such as Amazon S3, Azure Blob Storage, and Google Cloud Storage, and extension sources, can't do that without setup on your side, so they offer only **Periodic** and **Manual**. A RabbitMQ queue has no schedule at all: it consumes its queue from **Sync now** until **Stop sync**. An automatic source shows no **Next scheduled sync**, because the two-minute check isn't a sync.
:::

### What happens when a sync keeps failing

After a failed sync, scheduled syncs wait longer before each new try, up to one hour, until a sync succeeds. **Sync now** always runs, so use it once you've fixed the problem, for example after re-authenticating the [connector](/operational-guides/configure-connectors).

**Sync now** and any change to the source's type, connector, paths, or configuration run a full sync. Otherwise an **Automatic** source looks only at what changed.

### Process a Knowledge whenever its source changes

A source brings files in; each Knowledge connected to it decides when to process them. In the Knowledge's settings, on the **Sources** tab, open the source's **⋮** menu and select **Data processing settings**. Choose **Automatic** to process the data again every time the source brings in changes. This mode is available for every source type.

## Configure an extension-contributed source (ArXiv Catchup)

Extensions can add source types of their own. **ArXiv Catchup**, for example, downloads the PDFs of new papers in an arXiv category on each sync.

### Install the extension

Go to **Settings** → **Extensions** and install the **ArXiv Catchup** extension. A source-provider-only extension installs directly, with no extra configuration step.

### Add and configure the source

1. Go to **Settings** → **Sources**, select **Add**, and choose the **ArXiv Catchup** type. Extension sources appear with their own icon.
2. Select a **Group**, then an **Archive**, then a **Category**. These cascade through arXiv's fixed subject taxonomy, so each choice narrows the next.
3. In **Changes since**, choose how far back to look for papers.
4. Set **Max papers** (default `500`) to cap how many papers each sync fetches.
5. Select **Add**. Rational AI creates the source and runs its first sync, which downloads the PDFs.

### Keep it in sync

To sync the source automatically, open its **⋮** menu, select **Sync settings**, and choose **Periodic** with a **Sync schedule** (for example **Every day**). Otherwise select **Sync now** whenever you want the latest papers.

arXiv limits bulk downloads, so keep **Max papers** (at most `5000`) as low as you can.

## Let the Fetch extension ignore robots.txt

The **Fetch** extension respects `robots.txt` by default. To let it fetch pages a site's `robots.txt` disallows, select **Ignore robots.txt** in the extension's configuration under **Settings** → **Extensions**.
