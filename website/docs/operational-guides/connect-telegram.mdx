# Connect a Telegram bot

A Telegram channel lets people chat with a [touchpoint](/operational-guides/configure-touchpoints) through a Telegram bot. Each exchange appears in [Conversations](/cr/Conversations).

## Prerequisites

- **A bot token from BotFather.** Message [@BotFather](https://t.me/BotFather) on Telegram, create a bot, and copy the token it gives you.
- **Permissions:** a role with **Create** and **Update** on **Channels**.
- **A touchpoint to answer**, or the plan to create one.

## Connect the bot

1. Go to **Settings** → **Channels** and select **Add**.
2. Choose **Telegram** as the **Channel type**.
3. Enter a **Name** and paste the token into **Bot Token**.
4. Choose the [reply mode](/operational-guides/manage-channels#choose-the-mode): **Automatic** if the assistant should answer on its own.
5. Leave **Transport** on **polling**, which needs no public address. Choose **webhook** only if Rational AI is reachable from the internet over HTTPS.
6. Select **Save**. Rational AI checks the token with Telegram, and the channel isn't created if the check fails.
7. Open the touchpoint that should answer and, on its **Settings** tab, select this channel as its **Channel**. The touchpoint must be enabled. If several enabled touchpoints use the channel, the one created first answers.

The channel's details show the bot's **@username** and a `t.me` QR code you can share with the people who should use the bot.

## What the assistant can receive

- **Text and captions.**
- **Photos, documents, video, audio, voice messages and video notes**, within the channel's [attachment settings](/operational-guides/manage-channels#control-what-can-be-sent-in). The size limit defaults to 20 MB, the most a Telegram bot can download. The assistant reads the text of documents and the transcript of voice messages.
- **Locations, contacts and polls**, turned into text.

Photos sent together as an album reach the assistant as one message, so it answers once.

## How conversations are grouped

Each Telegram chat is its own conversation. In groups with topics, each topic is its own conversation too.

Users can send these commands:

- **`/reset`** closes the current conversation, so the next message starts a fresh one.
- **`/start`** and **`/help`** reply with the text you enter in **Welcome message**.

## Control replies in group chats

In groups, the bot answers only when it's @mentioned, replied to, or sent a command aimed at it. Other messages are skipped without a reply, and the bot never replies to other bots.

- To have it answer every message in a group, set **Group replies** to **always** instead of the default **mention**.
- **Rate limit (messages/minute per chat)** caps how many messages one chat may send per minute. The default is 20; `0` turns the limit off. Messages over the limit get no reply.

## Give specific chats their own instructions

In **Per-chat prompts**, enter one line per chat: the chat ID, a pipe, and the instructions, for example `-100987654321 | Answer in French.` For a group, the chat ID appears in the conversation name. The instructions are added to the touchpoint's system prompt for that chat only, so one bot can answer an internal group and a public one differently.

## What replies look like

Replies use the formatting Telegram supports: headings become bold and lists become bullets. A reply longer than Telegram's 4,096-character limit is split at paragraph breaks into several messages.

- In groups, replies quote the message they answer.
- A 👀 reaction shows the message was received and turns to ✅ once the answer is delivered.
- The typing indicator shows while the assistant is writing.

The assistant can't send files, and each answer arrives complete rather than word by word.
