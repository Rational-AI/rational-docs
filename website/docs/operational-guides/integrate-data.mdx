# Integrate external data

To make files from an external service searchable in a Knowledge, you connect three pieces: a [connector](/operational-guides/configure-connectors) that holds the credentials, a [source](/operational-guides/configure-sources) that says which files to sync, and the Knowledge that processes them. This page walks through the whole path with Google Drive. Other providers follow the same steps with their own credentials; see [Available providers](/operational-guides/configure-connectors#available-providers).

## Prerequisites

- **Create** on the **Connectors** and **Sources** rows of your role. See [Manage roles and users](/operational-guides/roles-and-users).
- **The Knowledge module in your license.** **Sources** is hidden without it.
- **A [Knowledge](/operational-guides/create-knowledge)** to receive the files.
- **A Google Cloud project** where you can create OAuth credentials.

## Integrate Google Drive data

### 1. Create OAuth credentials in Google Cloud

1. In the [Google Cloud Console](https://console.cloud.google.com/), open your project and enable the **Google Drive API** under **APIs & Services** → **Library**.
2. Under **APIs & Services** → **OAuth consent screen**, set up the consent screen. Choose **Internal** to limit sign-in to your Google Workspace.
3. Under **APIs & Services** → **Credentials**, create an **OAuth client ID** of type **Web application**.
4. In **Authorized redirect URIs**, add the address you open Rational AI at, followed by `/api/management/v0/oauth/callback`. For example, `https://ai.example.com/api/management/v0/oauth/callback`.
5. Copy the **Client ID** and **Client Secret**.

### 2. Add the Google connector

1. In Rational AI, go to **Settings** → **Connectors** and select **Add**.
2. Choose **Google**.
3. Enter a **Name**, for example *Marketing Drive*, and paste the **Client ID** and **Client Secret**.
4. Select **Add and authorize** and sign in with the Google account whose files you want to sync.

### 3. Add a Google Drive source

1. Go to **Settings** → **Sources** and select **Add**.
2. Enter a **Name**, for example *Marketing team Drive*.
3. In **Type**, find **Google Drive** and select your connector under it.
4. In the file panel, select the folders, shared drives, or files to sync. Use *"Filter files and folders..."* to narrow the tree. A selected folder is synced with everything inside it.
5. Select **Add**. Rational AI creates the source and runs its first sync.

### 4. Choose when the source syncs

After the first sync, a new source syncs only when you select **Sync now**. To keep it up to date, open the source's **⋮** menu, select **Sync settings**, and choose **Automatic** or **Periodic**. See [Choose when a source syncs](/operational-guides/configure-sources#choose-when-a-source-syncs).

### 5. Attach the source to a Knowledge

1. Go to **Settings** → **Knowledge**, open the Knowledge, and select the **Sources** tab.
2. In **Add source...**, select the source. It's added at once.
3. To process the synced files now, open the source's **⋮** menu and select **Process now**. To process changes whenever the source syncs, see [Process a Knowledge whenever its source changes](/operational-guides/configure-sources#process-a-knowledge-whenever-its-source-changes).

## Troubleshooting

| Symptom | What to check |
|---|---|
| A red broken-link icon next to the connector | The sign-in failed or expired. Open the connector's menu, select **Complete authentication**, and sign in again. |
| The file panel lists no folders | The selected connector can't reach the service. Fix its authentication on the **Connectors** page, then add the source again. |
| Google shows a redirect URI error during sign-in | The **Authorized redirect URIs** entry must match the address you open Rational AI at exactly, followed by `/api/management/v0/oauth/callback`. |
