# AI-generated image label

Every PNG or JPEG image that Gen generates, including the ones a chat creates through Gen, carries a metadata label that says a model made it. There is nothing to turn on or configure.

## What the label contains

The label is an XMP metadata packet written into the file before it is stored. It holds two values:

- The IPTC digital source type `trainedAlgorithmicMedia`, the standard value for media created by a trained model. Search engines and social platforms read it when they tag content as AI-generated.
- The identifier of the model that made the image, as the creator tool, when it is known.

Because the label is inside the file, it stays with the image after a download, an export, or an API response. To check a file, open its metadata with a tool that reads XMP, such as ExifTool, and look for the digital source type. Images in other formats are stored without the label.

## What the label does not prove

The label states what the file is. It isn't signed, so it doesn't prove that nobody changed the file since, and anyone can remove it. It isn't a C2PA provenance record either, so it doesn't meet a requirement that asks for C2PA specifically.
