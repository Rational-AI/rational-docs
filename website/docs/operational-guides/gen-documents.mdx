# Generate documents, slides and web pages

In Gen's **Text**, **Slides** and **Canvas** areas you describe a document in a chat beside it, and the assistant writes the file (a Word document, a PowerPoint deck or an HTML page), keeping every version so you can go back to an earlier one.

:::note[What is a document session?]
Each document in Gen is a **session**: a chat with the assistant plus the files it has written. Every time the assistant writes the file, the result becomes a new **version** of the document. You keep talking (*"make the intro shorter"*, *"add a slide on pricing"*) and each answer produces the next version, while the earlier ones stay available.
:::

## Prerequisites

- **The Gen module in your license.**
- **Administrative access:** the **Text**, **Slides** and **Canvas** areas are available to administrators only; for other users they are grayed out.
- **The output skills installed:** each area writes its files with a [skill](/operational-guides/agent-skills) (**docx** for Text, **pptx** for Slides, **web-design** for Canvas). If the skill is missing, creating a document fails with a message asking an administrator to install it.

## Choose the area

| Area | What the assistant writes | Use it for |
|---|---|---|
| **Text** | Word documents | Reports, proposals, letters, policies. |
| **Slides** | PowerPoint presentations | Decks and one-off slides. |
| **Canvas** | An HTML page or an SVG image | Landing pages, one-pagers, diagrams, mock-ups. |

The Gen **Canvas** area keeps each page as a saved document with its versions. It is separate from the **Canvas** panel that opens beside a chat to preview a page a skill has built (see [Preview web pages in Canvas](/operational-guides/agent-skills#preview-web-pages-in-canvas)).

## Create a document

1. Select the **Gen** tab, then **Text**, **Slides** or **Canvas**.
2. Select the **Generate** tile and choose **Blank document**, or **From a template** to start from instructions an administrator has saved.
3. The editor opens with the document next to the chat. Until the first file exists it reads *"Ask for the document in the conversation. Every file the assistant writes shows up here as a new version."*
4. Describe what you need in the chat. Be concrete about the audience, the length and the structure.
5. To ground the document in your own material, select **Add knowledge**, choose the files from a [Knowledge](/operational-guides/create-knowledge), and select **Confirm**.

The assistant writes the file and it appears in the editor. Keep asking for changes in the chat; each file it writes becomes a new version.

## Work with versions

When a document has more than one version, a version menu appears above it: pick any version to view it. Gallery cards show how far a document has got: *"Draft"* before its first file, then *"1 version"*, *"2 versions"* and so on.

- **Text** and **Slides** versions open in the built-in office editor, so you see the document exactly as Word or PowerPoint would show it.
- **Canvas** versions show as **Preview**, the page rendered in a safe sandbox, or **Code**, its source.

:::note[Asking for a change never overwrites]
A new version is added next to the old ones rather than replacing them. If the assistant takes a request in the wrong direction, select the previous version and carry on from there; nothing has been lost.
:::

## Download a document

Select **Download** to save the version you are looking at: a `.docx` from Text, a `.pptx` from Slides, an `.html` or `.svg` file from Canvas.

To remove a document from the gallery, open its card menu, select **Delete** and confirm with **Delete document**. The document, its conversation and all its versions are deleted, and this can't be undone.

:::note[The assistant's behavior is set per area]
Which model writes the documents, the base prompt it follows, and the extra skills and tools it can use are configured separately for Text, Slides and Canvas under **Settings** → **Gen**. See [Configure Gen](/operational-guides/configure-gen#configure-text-slides-and-canvas).
:::
