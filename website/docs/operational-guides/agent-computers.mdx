# Agent computers

An agent does its work on a computer of its own: a Linux machine with a desktop and a browser, where it runs commands, writes files and picks up tomorrow where it left off today. This guide shows how to check and control those computers.

Each agent's computer keeps its files and installed skills between runs. It starts when a run needs it and stops after a period of inactivity, without deleting anything. It runs one job at a time, so other runs of the same agent wait in a queue.

## Prerequisites

- **Agent computers enabled on your installation.** When they are not, the computer panel says *"Computer environments are not enabled on this server. Contact your administrator to configure the service."*
- **Update rights on the agent** to start, stop or open its computer.

## Check the computers

Open **Agents** → **Computers**.

The page lists every agent with its computer and its open run, if any. The count at the top shows how many runs are open (*N open runs*).

- **With an open run**, the card shows *Open run* and its status, with **View run** and **Stop run**.
- **Without one**, it says *No open run*; the computer's own state is shown in its **Computer** panel.

The same **Computer** panel is on every agent's page.

| State | Means |
|-------|-------|
| **Not started yet** | The agent has never needed its computer. The first run, or **Start computer**, creates it. |
| **Running** | Up and ready. |
| **Idle** | Up, with no work; it stops on its own. |
| **Stopped** | Stopped; files and skills are kept. |
| **Disabled** | Computers are not enabled on this installation. |

## Control a computer

- **Start computer** starts it ahead of a run, so the first step does not wait.
- **Show desktop** opens the computer's desktop inside the page, **Open desktop** in a new tab. Watching the desktop while a run works is the quickest way to see what the agent is doing in its browser.
- **Stop** shuts it down. Files stay.
- **More computer actions** has **Install browser tools**, which installs a ready-made toolkit of browser automation and skills on the computer (**Reinstall browser tools** to update it), plus **Repair** and **Restart desktop**. Installing can take several minutes; the installed skills are listed under *N installed skills*. Restarting the desktop closes its open windows and keeps the files.

:::warning[The desktop is the agent's, not yours]
Whatever you do on the desktop happens on the agent's machine, in the middle of its work. Use it to watch, or to unblock something the agent asked you about (a sign-in page, a confirmation), not to work alongside it while a run is going. On the run page, **Take control** lets you use the desktop and **Hand back to the agent** returns it.
:::

## Troubleshooting

| Symptom | What to check |
|---------|---------------|
| *"Computer service was not found…"* or *"The server could not reach the Computer service…"* | The computer service is down or not configured. Contact your administrator; **Retry connection** tries again. |
| *"The Computer service did not respond in time."* | A computer is starting or under load. **Retry connection** after a few seconds. |
| Runs stay *Queued* | Another run of the same agent is using the computer. Check **Computers**; stop the open run if it is stuck. |
| The desktop shows *Disconnected* | Select **Reconnect**. If it keeps disconnecting, open it in a new tab with **Open desktop**. |
