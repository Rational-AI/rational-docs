# Import, export, and set timeouts

Export a [step](/operational-guides/create-workflow) or a [processing rule](/operational-guides/create-processing-rule) to copy it into another environment or hand it to a teammate. Import it there from the JSON file. You can also give a step a timeout, so a run that hangs is stopped.

Workflow graphs have no export, import, or timeout.

## Before you begin

- Role: on the **Workflows** row of your role, **Read** to export, **Create** to import, and **Update** to set a timeout. See [Manage roles and users](/operational-guides/roles-and-users).

## Export a step or rule

1. Go to **Settings** → **Workflows**. For a processing rule, select the **Processing rules** tab.
2. Select the step or rule.
3. Open its **⋮** menu and select one of these:
   - **Export (JSON)** saves the definition as a JSON file. This is the only format you can import.
   - **Download** saves the Python code as a `.py` file, to read or run on your own machine.

## Import from JSON

1. Go to **Settings** → **Workflows**.
2. Start the import:
   - For a step, select **+** next to **Steps**, then **Import JSON**.
   - For a processing rule, select the **Processing rules** tab, select **New**, then **Import JSON**.
3. Select one or more JSON files.

Each file opens as a draft in the list. Nothing is created until you open a draft and select **Save**. If a file isn't valid JSON, the message *An error occurred. Please, refresh and try again* appears, and the other files still import.

## Set a step timeout

1. Go to **Settings** → **Workflows** and select a step under **Steps**.
2. Open its **⋮** menu and select **Workflow Settings**.
3. In **Timeout (minutes)**, enter a whole number of 1 or more. Leave it empty to keep the default of 5 minutes per attempt.
4. Optionally, clear **Count runtime toward the tenant quota** for maintenance or synchronization steps that shouldn't use up the monthly workflow minutes.
5. Select **Save**.

The timeout applies to every later run of the step. A run that reaches it is stopped and tried again, up to three attempts in all. Processing rules have no timeout setting.
