# Annotate resources

Annotations let you highlight a passage in a resource and attach a label to it, enriching your data with user-defined metadata. This guide shows you how to annotate text in a `.txt` or `.md` resource using the selectable text viewer.

<Admonition type="info" icon="📖" title="WHAT IS AN ANNOTATION?">
An annotation marks a specific range of a resource and pairs it with a label and colour. For text resources, the range is stored as character offsets into the raw file — the same offsets used by chunking — so each highlight stays aligned to the exact text it refers to. Annotations appear inline in the viewer and are listed in the Annotations sidebar.
</Admonition>

## Prerequisites

Before you start, make sure you have:

- **A Knowledge** containing at least one resource (see [Create a Knowledge](/operational-guides/create-knowledge)).
- **A text resource** in a supported format: `.txt` or `.md`. Other formats such as `json`, `xml` and `html` open in the syntax-highlighted editor and cannot be annotated here.

<Admonition type="note" icon="📝" title="MARKDOWN IS SHOWN AS RAW SOURCE">
Markdown resources are displayed as raw source, not rendered HTML. This keeps the character offsets of each highlight aligned 1:1 with the stored file, so your annotations always point to the right text. The same viewer is shared by `.txt` and `.md`.
</Admonition>

## Open a text resource

1. Open the **Knowledge** tab from the main navigation and select the **card** for the Knowledge that holds your resource.
2. Locate your `.txt` or `.md` resource and open it. It renders in the **text viewer** as selectable raw text, with the **Annotations** sidebar on the right.

## Create an annotation

1. In the viewer, **select the text** you want to annotate by dragging across it.
2. When you release the selection, the **label/colour popover** opens.
3. Choose or enter a **label** and pick a **colour**.
4. Confirm to create the annotation.

The selected passage is highlighted inline in your chosen colour, and the new annotation is added to the **Annotations** sidebar with its label and colour.

<Admonition type="note" icon="📝" title="OVERLAPPING SELECTIONS">
If a new selection overlaps an existing annotation, the highlight clamps to the first range (the one with the earlier start). Nested or overlapping highlights are not currently supported.
</Admonition>

## Review and manage annotations

The **Annotations** sidebar lists every annotation on the resource:

- **Focus an annotation:** select an entry in the sidebar to scroll the viewer to that passage and briefly flash its highlight.
- **Delete an annotation:** remove it from the sidebar to clear the highlight from the text.

## Result

Your text resource now carries one or more labelled annotations. Each highlight appears inline in the viewer by character offset, and every annotation is listed in the Annotations sidebar where you can focus or delete it.
