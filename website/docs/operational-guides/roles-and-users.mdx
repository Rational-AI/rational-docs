# Manage roles and users

Roles define what members of your team can do in Rational AI, and users are the accounts that those roles apply to. This guide covers configuring roles from the settings and creating a user with a password you control.

<Admonition type="info" icon="📖" title="WHAT ARE ROLES AND USERS?">
A role is a named set of permissions that you assign to people in your organisation. Each permission is granted or revoked independently, so you can shape exactly what a role can see and do. Users are the individual accounts that sign in to Rational AI; each user is governed by the role you give them.
</Admonition>

## Prerequisites

Before you start, make sure you have:

- **Administrative access:** an account with privileges to manage settings, roles, and users.

## Configure roles

The **Roles** settings page is where you review existing roles and adjust their permissions.

1. Go to **Settings** → **Roles**.
2. Select the **role** you want to configure from the list.
3. In the **permissions matrix**, use the **chip controls** to grant or revoke each permission for that role. Each chip toggles a single permission on or off.
4. Repeat for any other roles you need to adjust.

<Admonition type="note" icon="📝" title="ONE PERMISSION AT A TIME">
Permissions are independent: turning one chip on or off affects only that permission. Review the full matrix for a role so its access matches what that group of users actually needs.
</Admonition>

## Create a user

When you add a new user, you can set the password yourself instead of relying on a generated value.

1. Open the **Create new user** dialog.
2. Fill in the user's details.
3. In the **Password** field, keep the password that has been generated for you, or type your own. The field is editable and required.
4. Use the **copy** button inside the field to copy the current password value when you need to share it with the user.
5. Leave **Require password change at first login** checked if you want the user to set their own password the first time they sign in. This is checked by default.
6. Submit the dialog to create the user.

<Admonition type="note" icon="📝" title="GENERATED BY DEFAULT">
A random password is generated automatically when the dialog opens, as the subtitle notes: "A random password is generated automatically, but you can change it." You only need to edit the **Password** field if you want to set a specific value.
</Admonition>

## Result

You have a set of roles whose permissions reflect what each group can do, and a new user account secured with a password you either accepted or chose. If you left **Require password change at first login** checked, the user will be prompted to change the password on their first sign-in.
