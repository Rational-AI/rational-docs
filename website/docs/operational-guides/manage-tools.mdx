# Browse the tools your touchpoints can use

**Settings** → **Tools** is the catalog of the MCP tools your [touchpoints](/operational-guides/configure-touchpoints) can call beyond chatting: search a knowledge base, run a read-only query, fetch a document, and more.

The agents of the [Agents](/cr/Agents) section are granted tools in their own profile, and **Agents** → **Library** lists what they can be granted (see [Browse the library](/operational-guides/create-an-agent#browse-the-library)).

:::note[What is a tool?]
A tool is one action the AI can take during a conversation, such as searching a Knowledge or fetching a document. Tools come from [extensions](/operational-guides/manage-extensions): an extension runs an **MCP server** (MCP is the open standard for connecting AI models to tools), and that server provides the tools.
:::

## Browse available tools

Go to **Settings** → **Tools**. The page is a searchable list of every tool currently available in your environment, grouped by MCP server configuration. Each group row shows the MCP server's name (for example **RAG MCP server**) and the configuration's name. The configuration created when an extension is installed is called **Default**. Groups start collapsed; expand one to see its tools.

Each tool row shows:

- **Name:** the tool's identifier.
- **Description:** a short explanation of what the tool does and when the AI would call it.
- **⋮** menu: **See details** opens the tool's page, with its parameters and a **Test tool** form to try it with **Run test**.

Use the search box to find a tool. While you search, every group is expanded.

The **RAG MCP server**, installed by default, provides the tools that search and query your Knowledges.

## Where tools come from

Extensions provide tools, this page lists every tool available, and a [touchpoint](/operational-guides/configure-touchpoints) is where you choose which tools an assistant may call. A tool listed here is used only by the touchpoints that enable it. To install or remove extensions, see [Manage extensions](/operational-guides/manage-extensions). For what happens to tools when an extension updates, see [Update and roll back extensions](/operational-guides/extension-updates).

## Give a slow MCP server more time

Every tool call has a time limit. A tool that hasn't answered in time is reported to the assistant as failed, and the conversation carries on. The limit is set on the touchpoint and applies to every MCP server it uses (see [Configure touchpoints](/operational-guides/configure-touchpoints)). When a single server is slow, for example one that runs a long query or calls a slow external service, give only that server more time:

1. Go to **Settings** → **Touchpoints**, select the touchpoint and open the **Tools** tab.
2. In the configuration's `⋮` menu, select **Configure MCP server**. To create a new configuration instead, use **Add MCP server configuration...** → **Add new configuration**.
3. In **Tool call time limit**, enter the number of seconds, from 1 to 600. The help text shows the limit the server follows when you leave the field empty: *"Only for this server. Leave empty to follow the touchpoint's limit of … seconds."*
4. Select **Save**.

| Where the limit is set | When it applies |
|------------------------|-----------------|
| **Tool call time limit** on the MCP server configuration | Always, for that configuration's tools. |
| **How long a tool may take** on the touchpoint | For every server configuration that has no limit of its own. |
| Platform default (120 seconds) | When neither of the above is set. |

:::note[An empty field never means no limit]
Leaving the field empty makes the server follow the touchpoint's limit, then the platform default. Every call has a limit.
:::
