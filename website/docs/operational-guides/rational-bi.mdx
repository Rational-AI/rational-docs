# Build BI dashboards

Rational BI is where you turn your data into business-intelligence dashboards: visual, shareable views that surface trends and answer questions at a glance. This guide shows you how to get started by creating your first project.

<Admonition type="info" icon="📖" title="WHAT IS RATIONAL BI?">
Rational BI is a dedicated area for building business-intelligence (BI) dashboards on top of the data already in Rational AI. Your work is organized into **projects** — a project is the central workspace that holds a related set of dashboards, so you can keep, say, your sales reporting separate from your operations reporting.
</Admonition>

## Open Rational BI

Select the **BI** tab in the top navigation. (You can also reach it from **Settings → Rational BI**.)

The first thing you see is your list of projects. If you haven't created any yet, this is an empty state inviting you to make your first one.

*The **BI** area: your projects. Each project is the workspace for a set of dashboards.*

## Create a project

Everything in Rational BI lives inside a project, so the first step is to create one.

1. From the **BI** area, select **New**.
2. Give the project a clear **name** — something that describes the dashboards it will hold, for example `Sales Reporting`.

Your new project appears in the list and opens as a workspace ready for you to start building.

<Admonition type="note" icon="📝" title="GROUP DASHBOARDS BY PURPOSE">
Use a separate project for each distinct reporting area or audience. Keeping related dashboards together makes them easier to find and to manage as your reporting grows.
</Admonition>

## Build dashboards inside the project

Once a project is open, you build your dashboards within it. A project can hold several dashboards, each presenting a different view of your data.

To make sure there's data worth visualizing, connect and prepare it first — see [Integrate external data](/operational-guides/integrate-data).

## Result

You have a Rational BI project — your workspace for a set of dashboards — and you know where to create more. From here, you can start building dashboards inside the project to explore and share insights from your data.
