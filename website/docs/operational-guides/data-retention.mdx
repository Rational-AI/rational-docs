# Set how long data is kept

Rational AI keeps what it records until you set a limit. Use **Settings** → **Data retention** to set how long prompt and response bodies, model call records, and closed conversations are kept, and each model's **Payload tracing** to decide whether prompt and response bodies are stored at all.

:::danger[Deletion is permanent]
Every period starts empty, which means *keep forever*. Once you set a period, data older than it is deleted and can't be recovered.
:::

## Prerequisites

- **Administrative access:** the retention policy is restricted to administrators.
- **A decision about what you need to keep**, ideally from whoever owns data protection in your organization.

## Decide what each model call stores

Every request to a model is logged in the [audit trail](/operational-guides/audit-trail). **Payload tracing** decides whether the content of those requests is stored too. It is set per model, for third-party and self-hosted models alike.

1. Go to **Settings** → **AI Model Registry**, open the model and scroll to **Payload tracing**.
2. For **Request payloads** (what was sent) and **Response payloads** (what the model answered), choose **Never**, **Only when the request fails**, **Only when the request succeeds** or **Always**.

The choice is saved at once. When an audit entry says a payload was not recorded, it links to this section of the model.

:::warning[Payloads can contain personal data]
Prompts and answers carry whatever people typed and whatever documents were sent. Prefer **Only when the request fails** over **Always**, and set a short **Prompt and response bodies** period.
:::

## Set the retention periods

1. Go to **Settings** → **Data retention**.
2. Enter a number of days for each period you want to limit. Leave a field empty to keep that data forever.
3. Select **Save**.

| Period | What it removes | What stays |
|--------|-----------------|------------|
| **Prompt and response bodies** | The prompt and response text stored by payload tracing | The call record: who, when, which model, how many tokens, what it cost |
| **Model call records** | The whole call record, bodies included | Nothing of that call |
| **Closed conversations** | Conversations that have ended, with their messages and Canvas artifacts | Nothing of that conversation |

The fields suggest 30 days for **Prompt and response bodies** and 365 days for **Model call records**. The suggestions are never applied for you. Governance dashboards and cost reporting read the call records, so clearing bodies doesn't change them.

The body period can't be longer than the **Model call records** period: the page refuses to save it.

The closed-conversation period counts from each conversation's last activity. An open conversation is never deleted, at any age.

## Check that deletion is running

Deletion runs every hour. The page header shows **Last sweep** and how many records that run removed. Until the first run, it reads *No sweep has run yet.* Most runs remove nothing once older data has been cleared, so a zero count is normal.

## What retention does not cover

- **Knowledge files.** Delete them from [Add and manage content](/operational-guides/manage-knowledge-resources).
- **The [audit trail](/operational-guides/audit-trail).** Its entries are never removed by these periods.
- **Legal hold.** You can't exempt a single conversation from retention. Export anything you must preserve before its period ends.
