# Configure Gen for your team

Generated content is only useful if it looks like it came from your organization. Under **Settings** → **Gen**, an administrator decides once which models Gen uses, what a good default image looks like, which brand styles and templates people start from, and how the document assistants behave, so everyone else can describe what they want.

:::note[Defaults, presets and templates]
Gen settings work in layers. **Generation defaults** are what every new image starts from. A **style preset** is a reusable look (a style text, a negative prompt and reference images) that people can switch on in the editor. A **template** is a complete starting point for one kind of image: model, settings, prompt and brand style together. People pick a template; the template falls back on the defaults for anything it doesn't set.
:::

## Prerequisites

- **The Gen module in your license:** without it, **Gen** doesn't appear in **Settings** either.
- **Administrative access:** other users with the module can open **Settings** → **Gen** and read its **Photo & video** tab, but the other tabs are grayed out for them and only administrators can change anything.
- **Models:** an image-generation model, and a text-generation model for the AI prompt rewrite and the document assistants, in the [AI Model Registry](/operational-guides/ai-model-registry-features).

## Open the Gen settings

Go to **Settings** and select **Gen**, in the **Capabilities** section. The page has one tab per Gen area: **Photo & video**, **Text**, **Slides**, **Canvas** and **Social**.

## Set the image defaults

1. In **Photo & video**, open **Prompt defaults**, then **Generation defaults**. On a new workspace you'll see *"Image generation isn't set up yet"*: select **Set up image generation**.
2. Choose the **Model** and the default settings every new image starts from: **Aspect ratio**, **Output quantity**, **Size**, **Quality**, **Background**, **Output format** and the rest. As in the editor, only the settings the model supports are offered.
3. Decide whether to turn on **Let AI rewrite short prompts**: *"Expands one-liners into a fuller prompt before generating."* It applies to prompts of twelve words or fewer.
4. Save.

:::note[The rewrite trades control for quality]
Most people type a few words, and most image models do far better with a full description. With the rewrite on, a text model fills in the composition, lighting and mood before the image model sees the prompt. People who want exact control can still get it by writing more than twelve words, which are always sent as written.
:::

## Create style presets

1. In **Prompt defaults**, open **Style presets** and add a preset.
2. Fill in its **Name**, **Description**, **Style text**, **Negative prompt**, **Strength** and **Reference images**.
3. Use **Set as default** on the preset that new images should use unless someone picks another. **Duplicate** is the quick way to make a variation.

## Create an image template

1. In **Photo & video**, select **New** to create a new template.
2. On the **General** tab, choose the **Model**, its image settings, and the **Generation prompt** that is added to whatever the user describes.
3. On the **Style** tab, set the brand: **Brand colors**, **Brand typography** (`.otf`, `.ttf` or `.woff` files), **Style reference** and the **Style prompt**.
4. Save, and make sure the template is enabled: only enabled templates are offered in **From a template**.

Use **Enable** or **Disable**, **Duplicate** and **Delete** on the template to manage it later. Administrators can also save a template straight from the image editor with **Save as template**.

## Configure the AI tools

The tools offered in the image editor's **AI Tools** menu are set up under **AI tools**, with one tab per tool: **Expand**, **Remove background**, **Paint** and **Improve quality**. For each one, set:

- **Model**: the image model that runs the tool.
- **Background**: or leave it to the model.
- **Prompt**: the instruction the tool sends with the image.
- **Enabled**.

:::note[A tool without a prompt isn't offered]
A tool appears in the editor only when it has a prompt. That keeps people from running a tool that would send the model an image with no instruction about what to do with it.
:::

## Configure Text, Slides and Canvas

Each document area has its own assistant, configured on its tab. Changes apply to documents created from then on.

1. Open the **Text**, **Slides** or **Canvas** tab and go to **Section defaults**.
2. Under **Generation**, choose the **Model** and write the **Base prompt** (house style, tone, length). **Section instructions** shows, read-only, the instructions the platform itself gives the assistant for this kind of document.
3. Under **Skills**, review the skills the assistant can use. The skill that writes the file (**docx**, **pptx** or **web-design**) is always on; add the supporting [skills](/operational-guides/agent-skills) you want.
4. Under **Tools**, add the MCP servers whose tools the assistant may call, configure them, or remove them.
5. Select **Save**. Until you do, your changes are a draft.

Each area also has **Templates** (a **Name**, a **Description** and a **Prompt**) that people pick with **From a template** when they create a document.

## Set up social templates

The **Social** tab holds the templates the [Social studio](/operational-guides/social-studio) builds posts from. They are covered in [Create social templates](/operational-guides/social-studio#create-social-templates).
