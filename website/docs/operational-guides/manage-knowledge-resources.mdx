# Add and manage content in a Knowledge

Upload files to a [Knowledge](/operational-guides/create-knowledge), follow their processing, fix the files that fail, and clean up the ones you no longer need. Each processed file becomes a resource that the AI can search and quote. The **Files** button in the Knowledge's header opens the table of input files and their processing status.

## Prerequisites

- **Read** on the **Knowledge** row of your role to browse files, **Create** to upload them, **Update** to reprocess or edit them, and **Delete** to delete them. See [Manage roles and users](/operational-guides/roles-and-users).

## Upload files {#upload-files}

1. Open the Knowledge and select **Add file** in the **Options** menu (in the **Grid**, the menu is **Actions**).
2. In **Add file**, add your files or a folder and select **Upload**.
3. In **Workflows review**, for each file, either pick a **workflow** or leave it on **Skip workflow** and select **Add as resource** to store the file as it is.
4. Select **Confirm**.

If the Knowledge has a processing rule, Rational AI skips the review step and the rule assigns each file its workflow. If you select **Cancel** in **Workflows review**, the files you uploaded are deleted.

To keep a Knowledge in sync with a folder or service instead, see [Integrate external data](/operational-guides/integrate-data).

## Follow a processing run

A processing run is one pass of the Knowledge's pipeline over its files. It starts when you select **Reprocess knowledge** in the **Options** menu, when a source finishes a sync, or when an API client asks for it.

1. Open the Knowledge and select **Files**. A status chip for the latest run sits on the folder header: on **Local** when the Knowledge has no sources, otherwise on each source's folder.
2. While the run is in progress, the chip shows the current step, and the bar and counter show files done out of the total (for example *120 / 480*). They refresh every 30 seconds.
3. When the run ends, a toast reads *"Processing complete"*, or *"Processing failed"* with the Knowledge name and the reason. It appears even if you moved to another tab.
4. If the run failed, was canceled, or timed out, the chip turns into an **Error** chip. Hover over it to read the cause.

The **Last processing** column shows how long each file's last attempt took, with its date underneath. Use it to find the slowest files.

### Recover a file that failed

1. In the files table, find the file with the **Error** chip in the **Status** column. Hover over the error text to read it in full.
2. Select **Reprocess** under the error.
3. Choose how to process the file and confirm.

When the error text isn't enough, open the row's **⋮** menu and select **See logs details**. The **Processing log** dialog lists each attempt with its **Time**, **Status**, and **Details**.

## Delete files

1. In the files table, select the rows to delete. To go beyond the page, select the header checkbox, then **Select all N**: it selects every file that matches your filters.
2. Open the **⋮** menu next to the selected count and select **Delete selected**.
3. Read the count in the **Delete resources** dialog and confirm.

After **Select all N**, changing any single checkbox clears the whole selection, so narrow the filters before you select all. The **Name**, **Updated at**, and **Size** columns are sortable, which helps find large or stale files.

:::danger[Deletion can't be undone]
Deleting a file also deletes everything extracted from it: chunks, embeddings, and annotations.
:::

## Edit a resource

When you edit a file's content in the Knowledge and save, Rational AI chunks and embeds the new text again, so [search](/operational-guides/configure-rag) reflects your edit. It doesn't rerun the file's workflow or processing rule, so content you wrote by hand, your annotations, and the record's attributes stay as they are.

To rerun the full pipeline, reprocess the Knowledge. A [source](/operational-guides/configure-sources) set to the **Automatic** sync mode in its **Data processing settings** reprocesses the files it brings in every time they change.
