# Limiti e quote

I limiti qui sotto sono imposti da Rational AI stesso. Un modello o un servizio esterno (Telegram, Instagram, un server di posta) può aggiungerne di propri. "Impostazione dell'installazione" indica che il valore fa parte della configurazione dell'installazione, non della Control Room.

## Chat e allegati {#chat-and-attachments}

Vedi [Usa la chat](/operational-guides/chat-experience) e [Memoria e chat lunghe](/operational-guides/touchpoint-memory).

| Limite | Valore | Dove si applica | Si può modificare? |
|---|---|---|---|
| Dimensione di un allegato | 25 MB | File allegati a un messaggio di chat, e file che arrivano da qualsiasi canale | No |
| Testo letto da un documento allegato | 200.000 caratteri | Testo estratto da un allegato e dato al modello. Per documenti più lunghi, aggiungili a una Knowledge | No |
| Pagine lette da un PDF allegato | 200 | Estrazione del testo dagli allegati PDF | No |
| Elementi di contesto | 10 | File, documenti, progetti e connettori scelti come contesto nel campo di scrittura del messaggio | No |
| Dimensione di una registrazione dettata | 25 MB | **Detta un messaggio** | No |
| Chiamate di strumento in una risposta | 40 | Risposte della chat, e risposte dei touchpoint tramite API | No |
| Errori consecutivi dello stesso strumento | 5 | La risposta si interrompe dopo il quinto errore di fila | No |
| Turni consecutivi con chiamate di strumento fallite | 3 | La risposta si interrompe dopo tre turni di fila in cui tutte le chiamate di strumento sono fallite | No |
| Anteprima di un foglio di calcolo o documento in Canvas | 25 MB | Anteprima in sola lettura nel pannello **Canvas** | No |
| File Office modificato in Canvas | 25 MB | Modifica di file Word, Excel e PowerPoint con l'editor Office | Impostazione dell'installazione |
| Un ricordo | 280 caratteri | Memoria personale e condivisa del touchpoint | No |
| Memoria personale per persona | 1.500 caratteri in totale | La memoria di ciascuna persona su un touchpoint | No |
| Memoria condivisa | 3.000 caratteri in totale | La memoria condivisa da tutti su un touchpoint | No |

| Definizione o formula di un attributo | 16.384 caratteri | Impostazioni e formule degli attributi | No |

| Link in un attributo di tipo link | 500 per record | Attributi di tipo link | No |
| Righe salvate insieme | 1.000 | **Salva** nella griglia, e salvataggi in blocco tramite API | No |
| Condizioni in un filtro | 100 | Filtri della griglia e query sui record | No |
| Livelli di raggruppamento | 3 | Raggruppamento della griglia | No |
| Viste fissate | 5 per Knowledge | Il selettore delle viste | No |
| Record in un calendario | 1.000 alla volta | Viste calendario | No |
| Nodi disegnati nel grafo | 2.000 per impostazione predefinita | La vista grafo | Sì: **Aspetto** → **Numero massimo di nodi** (2.000, 5.000 o 10.000) |
| Cronologia di un record | 500 voci per record, conservate per 24 mesi | La cronologia di un record | No |
| Nome di un promemoria | 128 caratteri | Promemoria | No |
| Anticipo di un promemoria | 366 giorni | **giorni prima di** o **giorni dopo** la data del promemoria | No |
| Attesa per un'esportazione | 2 minuti | Esportazione di una Knowledge da **Impostazioni** | No |
