# Connettori

Un connettore conserva le credenziali e la configurazione necessarie per comunicare con un provider esterno, come Google, AWS, OpenAI, Anthropic, Google Vertex AI, Microsoft SQL Server o RabbitMQ. Una volta configurato, un connettore può essere riutilizzato in tutta la piattaforma: dai [modelli AI](ai-model-registry.mdx) (per raggiungere le API di un provider), dalle [fonti](sources.mdx) (per leggere i tuoi dati) e dagli [strumenti](extensions.mdx). Usa questa sezione per aggiungere connettori e vedere dove viene usato ciascuno.

## Sfoglia i connettori {#browse-connectors}

/>

La pagina Connettori elenca ogni connettore come una scheda, con il suo nome e l'icona del provider. Usa la casella di **ricerca** per filtrare per nome, e seleziona una scheda per aprirne i dettagli.

Il pannello dei dettagli mostra la descrizione del connettore, il suo **Provider** e quante volte viene usato. Una ripartizione dell'utilizzo indica quanti **Modelli AI**, **Sources** e **Tools** dipendono dal connettore, così puoi vedere che cosa sarebbe interessato prima di modificarlo o rimuoverlo.

Un connettore ancora usato da modelli AI, fonti o abbonamenti dei provider non può essere eliminato. Gli abbonamenti dei provider non sono contati nella ripartizione dell'utilizzo, quindi controlla anche gli abbonamenti del connettore prima di eliminarlo.

## Aggiungi un connettore {#add-a-connector}

Seleziona **Aggiungi** per aprire **Aggiungi un nuovo connettore**. In **Sfoglia connettori**, seleziona un provider, poi inserisci un **Nome** e le credenziali richieste, come una chiave API o i dati di un account di servizio. Il catalogo è un unico elenco; la tabella raggruppa i provider per uso.

| Uso | Provider |
|-------|-----------|
| Modelli AI | OpenAI, Anthropic, OpenRouter, Xference, MiniMax, OpenAI Compatible, Google Vertex AI |
| Decisioni | System One Compatible |
| Fonti dati | Google, AWS, Azure, Google Service Account Key, Microsoft OneDrive, Git credentials, RabbitMQ |
| Database virtuali | Database SQL (PostgreSQL, MySQL, SQLite, SQL Server, Oracle o IBM i) |
| Strumenti ed estensioni | Brave Search, Microsoft SQL Server |
| Pubblicazione | LinkedIn, Instagram, Facebook |

Alcuni provider chiedono più di una chiave: **Google Vertex AI** richiede un ID progetto e una sola regione e non salva alcuna credenziale, **Microsoft SQL Server** richiede un host, un database e un accesso di sola lettura con l'interruttore facoltativo **Cifra la connessione**, e **RabbitMQ** richiede un host del broker, un utente e un token facoltativo per il download dei file. Vedi [Configura un connettore](/operational-guides/configure-connectors#available-providers) per ciascuno di essi.

:::warning
I connettori contengono credenziali sensibili. Rimuovere o modificare un connettore influisce su ogni modello AI, fonte e strumento che ne dipende. Controlla la ripartizione dell'utilizzo nel pannello dei dettagli prima di apportare modifiche.
:::

## Gestisci un connettore {#manage-a-connector}

Per modificare un connettore, cambia i campi in **Configurazione** nel pannello dei dettagli e seleziona **Salva**, oppure **Annulla** per scartare le modifiche. I campi segreti non vengono mai mostrati: inserisci un nuovo valore solo per sostituire quello salvato. Per un connettore **Database SQL**, **Prova connessione** ed **Esplora schema** verificano le impostazioni salvate.

Apri il menu opzioni (i tre puntini verticali) nel pannello dei dettagli per:

| Azione | Descrizione |
|--------|-------------|
| **Completa l'autenticazione** | Termina l'accesso per un connettore che lo richiede ancora (visibile solo in questo caso). |
| **Elimina** | Rimuove il connettore dalla piattaforma. |
